使用説明書

本ツールは判定の補助（該当項目数の集計・整理）を行う院内業務用アプリです。最終的な診断は担当歯科医師が総合的に判断します。データは端末内（localStorage）のみに保存され、外部送信はありません。
機

4つの機能

① 口腔機能低下症（成人・高齢者）
検査7項目の数値を入力 → 該当／非該当を自動判定。実施項目のうち3項目以上該当で「判定基準を満たす」と表示（診断は医師）。前提（50歳以上 or 全身疾患による機能低下 ＋ 歯科疾患管理料）を満たすと「算定候補」に管理料1/2・検査点数が表示。「印刷 / PDF」で結果シートをA4出力。
※患者にお渡しする印刷物には算定点数は出ません（検査値・判定のみ）。点数は画面上の「算定候補」でスタッフが確認します。
② 口腔機能発達不全症（小児）
離乳完了前／後を選択 → C項目チェックで診断・算定要件を自動判定（食べる＋話すで2項目以上・うち1つは必須の項目＝診断。2項目＝管理料2、3項目以上＝管理料1の区分を表示）。カウプ／ローレル指数も自動計算。「印刷 / PDF」でチェックシート（カルテ添付）＋管理計画表（保護者用・様式1）の2枚をA4出力。
③ 算定リファレンス（スタッフ用）
成人・小児の検査／管理点数、同時算定の組み合わせ、月次イメージを一覧で確認できる閲覧専用資料。診断・算定とは別の業務参考資料で、患者へ渡す資料ではありません。
設定（マスタ管理）
点数・該当基準値・施設基準フラグを編集（自動保存）。「マスタを初期値に戻す」で既定値に復帰。
起

起動方法

Mac：アプリ/index.html をダブルクリックで単体動作。
iPad（アイコン起動・オフライン）：
  1. アプリ/ フォルダを社内サーバー等に https で配置（iOSのオフライン動作にはhttps配信が必要）
  2. SafariでURLを開く → 共有ボタン →「ホーム画面に追加」
  3. 追加されたアイコンから全画面・オフライン起動
※ file:// で直接開いた場合は単体動作のみ（オフライン保存なし）。
印

印刷 / PDF

画面右上「印刷 / PDF」で印刷ダイアログが開きます。保存ファイル名は「氏名_日付」で自動設定。次の患者は右上「新規」でリセットしてください（共用端末では患者ごとに必ず実施）。
iPadで「PDFを保存」したときの保存先
固定の自動保存フォルダはなく、保存時に場所を選びます。
  1. 「印刷 / PDF」を押す → 印刷プレビュー表示
  2. プレビューを2本指で外側に広げる（ピンチアウト）→ PDFが全画面に
  3. 右上の共有ボタン（□に↑）をタップ
  4. 「ファイルに保存」→「このiPad内」（端末内・オフライン）または「iCloud Drive」（クラウド）を選択 → そのフォルダに保存。後で「ファイル」アプリで開けます。
    ※「ブックに保存」なら Apple Books へ。AirPrintプリンタを選べばその場で印刷も可。
※保存先が分からなくなったら「ファイル」アプリの検索に氏名や日付を入力（ファイル名＝氏名_日付）。共用iPadでは患者情報PDFの保存先の扱いに注意し、院内ルールに従ってください。
